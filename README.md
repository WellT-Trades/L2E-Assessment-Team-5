# JSON Diff and Validation Tool

## 1. Project Overview

The JSON Diff and Validation Tool is a Python web application that compares two JSON documents and validates JSON data.

It identifies added, removed, and modified fields, checks JSON syntax, and validates data against an optional JSON Schema.

## 2. Features

* Compare two JSON documents.
* Detect added, removed, and modified fields.
* Identify changes in nested objects.
* Validate JSON syntax.
* Validate JSON data against a JSON Schema.
* Display readable comparison and validation results.
* Handle invalid JSON input.
